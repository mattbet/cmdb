# cmdb

> Configurare un insieme di strumenti opensource che raccolga dati da varie sorgenti e ne permetta la riconciliazione, per alimentare un CMDB.
 
 
>**Strumenti di supporto utilizzati**

[Notepad++](https://notepad-plus-plus.org/) Editor di base

[MD WYSIWYG Editor](https://chromewebstore.google.com/detail/md-wysiwyg-editor/elmdnkbmhoofobbpboiakienehhahcde) 

A powerful Markdown editor with split-view layout, CodeMirror integration, bidirectional sync, and LaTeX math support.

[Docker Desktop](https://www.docker.com/products/docker-desktop/) 

The #1 containerization software for developers and teams

[LibreDB Studio](https://github.com/libredb/libredb-studio)

The database editor that deploys next to your data, not onto your laptop.



>**Strumenti  utilizzati**


[Apache Airflow ](https://airflow.apache.org/)

Apache Airflow® is a platform created by the community to programmatically author, schedule and monitor workflows.

[PostgreSQL](https://www.postgresql.org/)

The World's Most Advanced Open Source Relational Database
